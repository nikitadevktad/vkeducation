# RuStore | VK Education

## О проекте

Учебный проект, разрабатываемый в рамках образовательной программы **VK Education**.

Проект посвящён поэтапному созданию Android-приложения, изучению современных подходов к мобильной разработке и применению полученных знаний на практике.

## Технологии

- Kotlin
- Jetpack Compose
- Material 3
- Gradle Kotlin DSL
- Android SDK
- Hilt

## Текущая реализация

На данном этапе создана базовая структура Android-приложения.

Реализованы стартовый экран на Jetpack Compose, настройка темы приложения и первоначальная конфигурация проекта.

Hilt создаёт `GreetingViewModel` и передаёт ей `GreetingRepository`. Связь интерфейса с реализацией настроена через `@Binds`.
