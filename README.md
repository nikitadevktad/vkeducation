# RuStore | VK Education

## О проекте

Учебное Android-приложение с каталогом приложений, создаваемое в рамках VK Education.

## Технологии

- Kotlin
- Jetpack Compose
- Material 3
- Coroutines и StateFlow
- Retrofit и Gson
- Hilt

## Реализовано

- Получение каталога через Retrofit
- Отображение состояний загрузки, ошибки и пустого каталога
- Повторная загрузка после ошибки
- Запрос данных отдельного приложения по идентификатору

## Статус

Проект находится в разработке.
